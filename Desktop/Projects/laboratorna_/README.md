# Морфологічний аналізатор української мови

Морфологічний аналізатор української мови з інтерактивним веб-інтерфейсом на базі Gradio. Проєкт виконує лематизацію текстів, аналіз частин мови та виявляє граматичні характеристики.

# Структура проєкту
`app.py` — головний файл для запуску веб-інтерфейсу (Gradio).
`morphanalyzer/` — основний пакет із бізнес-логікою та модулями аналізатора (`core.py`).
`tests/` — папка з модульніми тестами (`pytest`).
`tests/data/` — текстові файли для перевірки та тестування.
`pyproject.toml` — конфігурація проєкту та менеджер залежностей (`uv`).
